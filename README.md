# L'Étoile - High-End Restaurant Landing Page

A luxurious, modern, and fully responsive landing page for a premium dining restaurant, designed with UI/UX best practices.

## Features
- **Modern Design**: High-end aesthetic with a dark theme, gold accents, and elegant typography (Playfair Display & Poppins).
- **Responsive Layout**: Optimized for all devices (Mobile, Tablet, Desktop).
- **Interactive UI**: 
  - Sticky glassmorphism navigation bar.
  - Scroll-reveal animations for a dynamic feel.
  - Menu filtering system (All, Starter, Main, Dessert).
  - Image hover zoom effects.
- **Functional Components**: 
  - Dynamic mobile menu.
  - Form validation for table reservations.
  - "Scroll to top" button.

## Technologies Used
- HTML5 & CSS3
- Tailwind CSS (via CDN)
- Vanilla JavaScript
- Font Awesome (Icons)
- Google Fonts

## Setup
Simply open `index.html` in any modern web browser to view the landing page. No build process required.
